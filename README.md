# fixupcopy

it's just a browser extension to copy (x)twitter links without tracking and with fixupx... nothing else

i'm sure a dozen others like this exist, but ehh i was bored and i haven't made a browser extension in a bit

## install

- clone the repo
- go to `[browser]://extensions` (browser can be chrome or helium or etc.)
- enable dev mode
- load unpacked
- reload (x)twitter and off you go!
